Project Analysis

Product Scope

AudioLoom is a full-stack web application for browsing and purchasing audio products with complete account and order flow.

It was initially developed during my MERN internship at Pooja Infotech, Vadodara (January 2025 to April 2025), then expanded into a production-style portfolio project.

Key Features Implemented

  • User authentication: login/logout and token-based protected operations.
  • Password recovery flow with OTP verification and reset password handling.
  • Product listing, product detail view, and search capability.
  • Cart management, checkout flow, and order placement.
  • Profile management with profile image update support.
  • Dashboard/admin flow with product creation and product management actions.

API Integration Observed

  • `/api/products`, `/api/products/:id` for catalog and detail data.
  • `/api/orders` and `/api/summary` for order and dashboard data.
  • `/api/profile`, `/api/user`, `/api/users` for user account operations.
  • `/api/reset-password` for recovery and account access restoration.

Engineering Value

This project demonstrates full-stack architecture thinking: frontend UX, secure account flow, backend route design, and deployment-ready integration in one system.

Product Scope

CyberDom is a cyber-themed, gamified coding challenge engine built with pure HTML, CSS, and JavaScript (no frameworks, no build tools).

It focuses on learning tracks (HTML, CSS, JavaScript) with a sleek animated UI and instant feedback loops.

Key Features Implemented

  • Gamified challenges across HTML, CSS, and JavaScript tracks.
  • Live "type command" style input with validation and instant feedback.
  • Signup/login/logout with session handling.
  • Admin dashboard to view registered users and export to CSV.
  • Animated cyber UI (glass panels, scanlines, FX/particles).

Data & Storage

  • User registrations stored in `localStorage`.
  • Login session state managed via `sessionStorage`.
  • CSV export generated in-browser (no backend).

Engineering Value

This project showcases strong fundamentals: vanilla JavaScript architecture, UI/UX polish with animations, and complete auth/admin flows without external dependencies.
